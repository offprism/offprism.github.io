OffPrism Piano v1.0.0 — the first release

ReleaseOct 12, 2026

OffPrism is a fork of Prism Launcher for people who play without a Microsoft license or through a skin service.

What's inside

  • Offline accounts without a Microsoft account.
  • Ely.by accounts — your skin in the launcher and in game without mods, two-factor authentication supported.
  • authlib-injector accounts for any compatible skin server (LittleSkin, Blessing Skin and others). authlib-injector is built in.
  • Glass theme — a dark, translucent theme.
  • Automatic updates from GitHub releases.
  • Builds for Windows x64, Windows ARM64, Linux and macOS.

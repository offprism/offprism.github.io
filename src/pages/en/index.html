Accounts

Play the way you want

Three ways to sign in without a Microsoft license — and a skin everyone on the server can see.

Offline

Type a nickname and play. No sign-up, no Microsoft account.

Ely.by

Your Ely.by skin in the launcher and in game — no mods. Two-factor authentication supported.

authlib-injector

Any compatible skin server — LittleSkin, Blessing Skin and more. Built right in.

Own the game? Microsoft accounts work too.

Features

Everything for mods, in one window

OffPrism is built on Prism Launcher, so it does everything Prism does.

One-click modpacks

Modrinth, CurseForge, FTB, Technic and ATLauncher — installed and updated with changelogs.

Built-in mod browser

Find mods, resource packs and shaders without leaving the launcher. Dependencies install themselves.

Isolated instances

Every instance keeps its own mods, worlds and settings. They never get in each other's way.

Updates that just happen

Update every mod with one button. The launcher updates itself from GitHub releases.

Glass theme

A dark, translucent theme — on top of all the themes and icon packs Prism ships.

No ads, no tracking

No ads and no telemetry. Passwords are never stored — only the session token.

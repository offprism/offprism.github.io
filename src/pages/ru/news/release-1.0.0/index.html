OffPrism Piano v1.0.0 — первый релиз

Релиз12 октября 2026

OffPrism — форк Prism Launcher для тех, кто играет без лицензии Microsoft или через сервисы скинов.

Что внутри

  • Офлайн-аккаунты без аккаунта Microsoft.
  • Аккаунты Ely.by — скин в лаунчере и в игре без модов, поддержка двухфакторной защиты.
  • Аккаунты authlib-injector для любого совместимого сервера скинов (LittleSkin, Blessing Skin и другие). authlib-injector встроен.
  • Тема Glass — тёмная полупрозрачная тема.
  • Автообновления из релизов на GitHub.
  • Сборки для Windows x64, Windows ARM64, Linux и macOS.

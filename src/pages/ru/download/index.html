Перед первым запуском

Сборки не подписаны платным сертификатом, поэтому система может переспросить.

Windows

Если появится SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае».

macOS

Откройте приложение через правый клик → «Открыть» или разрешите его в «Конфиденциальность и безопасность».

Linux

Сделайте файл исполняемым: chmod +x OffPrism-Linux-x86_64.AppImage

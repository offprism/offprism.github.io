OffPrism Piano v1.0.1

ReleaseOct 12, 2026

A round of fixes after the first release.

Fixed

  • Glass theme no longer breaks windows — settings pages used to be painted on top of each other. The theme now paints the interface opaque and makes the whole window translucent instead.
  • News in the launcher now comes from this website instead of the Prism Launcher feed.
  • After signing in with Microsoft, the browser opens an OffPrism page.

How to update

If OffPrism is already installed, it will offer the update by itself. For a fresh install, head to the download page.

Исправления после первого релиза.

Исправлено

  • Тема Glass больше не ломает окна — раньше страницы настроек рисовались друг поверх друга. Теперь тема рисует интерфейс непрозрачно, а полупрозрачным делает окно целиком.
  • Новости в лаунчере берутся с этого сайта, а не с сайта Prism Launcher.
  • После входа через Microsoft в браузере открывается страница OffPrism.

Как обновиться

Если OffPrism уже установлен, он сам предложит обновиться. Для новой установки откройте страницу загрузки.
